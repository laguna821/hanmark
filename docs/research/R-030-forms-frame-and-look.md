# R-030 — 공문서 양식을 틀과 모양으로 나누기, 중앙행정기관 52곳 모양

- 상태: REQUIRED (구현·검증한 사실은 CONFIRMED, 7절 항목은 OPEN)
- 작성일: 2026-11-18
- 최종 갱신: 2026-11-18
- 기준 버전/커밋: M1 엔진 이식 fa108aa (Kordoc 4.25.0) → 작업 브랜치 `m2-forms`
- 관련 문서: R-022(공문서 계약), R-024(한림대 양식), R-025(종류별 틀), R-026(양식 한 목록), R-028(노트별 양식·여러 양식), R-029(엔진 이식과 고정값)
- 담당 범위: 양식 id와 선택 모델, 모양 목록과 고르는 화면, 노트 속성, 설정 이전, 파일 이름, 2.7.x 출력 유지 검증

## 1. 조사 질문

2.7.x의 양식 10개 한 줄 목록을 틀(쪽 구성)과 모양(글꼴·크기·부호·색) 두 가지 선택으로 바꾸면서, 다음 세 가지를 함께 지킬 수 있는가.

1. Kordoc 4.25.0에 들어 있는 중앙행정기관 52곳 서식을 추가 설치 없이 고르게 한다.
2. 2.7.x에 있던 양식은 출력이 그대로다.
3. 2.7.1이 저장한 설정과 노트는 그대로 열린다.

사용자 결정(2026-11-18): 재정리안 그대로 진행. 통지·안내와 회의록은 "일반 문서" 하나로 합친다.

## 4. 확인된 사실

1. 2.7.x 양식 10개의 뼈대는 6개다. 계획서는 보고서에 표지를 붙인 것이고, 회의록과 통지·안내는 글자 크기와 맺음 줄만 다르다. 한림대 2종은 회의록·보고서 뼈대에 모양을 입힌 것이다.
2. Kordoc 4.25.0의 `agencyNames()`는 `공통`을 빼고 52개 기관을 준다. `gongmun.agency`는 보고서·계획서·개조식·업무보고·보도자료에만 적용되고, 다른 종류에 주면 무시하고 경고한다.
3. 52곳 가운데 15곳은 보고서 실측 문서가 5건 미만이거나 없다(`agencyStyle(name).report.docs`). 목록을 HanMark에 따로 두지 않고 이 값으로 계산한다.
4. 기관 모양은 header.xml의 글꼴과 글자 모양을 바꾼다. 같은 노트에서 국세청과 개인정보보호위원회는 header.xml이 서로 다르고, 기본 모양과도 다르다(네 틀 모두 테스트로 확인).
5. 보고서·계획서의 목차(`toc`)는 4.25.0에서 실제로 목차 쪽을 만든다. 서울방침(`bangchim`)은 앞장(`cover`), 점검표(`checklist`), 목차(`toc`)를 받는다.
6. 서울방침 앞장의 날짜는 엔진 기본값이 "2026. 11.."으로 찍힌다(R-025가 기록한 보고서 표지와 같은 현상). `withCoverDate`가 서울방침도 "2026. 11."로 채운다.
7. 새 모델에서 2.7.x 양식 10개의 section0.xml·header.xml은 fa108aa와 바이트가 같다. 옛 id로 불러도, 새 id로 불러도 같다.
8. 같은 입력은 두 번 생성해도 HWPX 바이트가 같다(틀 7개 × 허용 모양).

## 5. 결정

### 5-1. 틀과 모양

| 틀 | Kordoc 종류 | 틀 선택 | 2.7.x에서 |
|---|---|---|---|
| 기안문 | official | 없음 | 기안문·시행문 |
| 일반 문서 | 맺음 줄 끔 = minutes, 켬 = notice | 맺음 줄 | 회의록, 통지·안내 |
| 보고서 | 표지 끔 = report, 켬 = plan | 표지, 목차 | 보고서, 계획서 |
| 개조식 보고서 | gaejosik | 표지(기본 켬), 목차(기본 켬) | 정부 표준 개조식 |
| 업무보고 | ministry | 없음 | 업무보고 |
| 보도자료 | press | 없음(담당자 표는 노트 속성) | 보도자료 |
| 서울방침 | bangchim | 앞장, 점검표, 목차 | 새로 추가 |

| 모양 | 쓸 수 있는 틀 |
|---|---|
| 기본 | 전부 |
| 공통, 중앙행정기관 52곳 | 보고서, 개조식 보고서, 업무보고, 보도자료 |
| 한림대 일송자유교양대학 | 일반 문서 |
| 한림대 AI융합연구원 | 보고서 |
| 내 양식 | 저장된 종류의 틀. 종류 없이 저장된 옛 양식은 모든 틀 |

- 문서 종류 하나에 맞춰 만든 모양(한림대 2종, 종류가 저장된 내 양식)은 틀과 틀 선택을 함께 정한다. 이때 틀 선택 칸은 보이지 않는다.
- 틀을 바꾸면 그 틀이 쓸 수 없는 모양은 기본으로 돌아간다. 쓸 수 있으면 유지한다.

### 5-2. 양식 id

- 한 문자열: `form:<틀>/<모양>[;선택=0|1…]`. 예: `form:report/agency:국세청;cover=1;toc=1`.
- 선택은 정해진 순서로, 틀의 기본값과 다를 때만 적는다. 같은 선택은 항상 같은 id다.
- 한 문자열로 둔 이유: 노트별 기억, 미리보기, 여러 양식으로 내보내기가 이미 양식 id 한 개를 주고받는다. R-026의 "한 번 고르면 종류와 모양이 함께 정해진다"가 그대로 유지된다.

### 5-3. 우선순위

1. 창에서 고른 틀·모양·틀 선택
2. 노트 속성(`공문_종류`, `공문_기관서식`, `공문_표지`, `공문_목차` 등)
3. 모양이 가진 서식(기관 실측값, 한림대 양식, 내 양식)
4. 엔진 기본값

- 틀 선택이 기본값이면 노트 속성이 정한다. 그래서 2.7.x 양식의 출력이 바뀌지 않는다.
- 양식을 고르지 않고 내보낼 때(명령 등)는 활성 양식에서 시작해 노트의 `공문_종류`가 틀을, `공문_기관서식`이 모양을 정한다. 모르는 이름이거나 틀이 쓸 수 없는 모양이면 지금 모양을 유지하고 보고서에 알린다.
- 내보내기 창은 노트의 `공문_기관서식`과 지금 고른 모양이 다르면 어느 쪽으로 만드는지 적는다.

### 5-4. M1 고정값(R-029) 가운데 푼 것

| 고정값 | 이번 처리 |
|---|---|
| 보고서·계획서 목차 | 목차 선택을 켜면 `toc: true`를 준다(4.15.7은 무시했다) |
| 개조식 표지 없음일 때 `bodyTitleBox:false`, `toc:true` | 창에서 표지를 끄면 `bodyTitleBox:true`(4.25.0의 첫 쪽 제목 상자)를 주고 목차는 선택값을 따른다. 노트 속성 `공문_표지: false`만으로는 종전 고정값 그대로다 |
| `totalRow:"keep"`, `layoutTables`, `scriptTags`, 저장 `structure`·`keepLineseg`, `hancomFallback`, `ocr` | 그대로 고정 |

### 5-5. 고르는 화면

- 모양은 드롭다운이 아니다. 단추를 누르면 찾기 칸과 목록이 열린다. 이름 일부를 치면 걸러지고, 위·아래 화살표와 Enter로 고르고, Esc로 닫는다.
- 아무것도 치지 않았을 때 위에 최근 사용(5개)과 즐겨찾기가 선다. 이어서 기본·공통, 한림대, 내 양식, 부 / 처 / 청 / 위원회 / 그 밖의 기관 순이다.
- 표본이 적은 기관에는 "표본 적음" 표시가 붙는다.
- 즐겨찾기는 별 단추로 켜고 끄며 바로 저장된다. 내보내면 그 모양이 최근 사용 맨 앞으로 간다.
- 상태 표시줄 메뉴와 여러 양식으로 내보내기는 같은 목록을 창으로 띄운다.
- 여러 양식으로 내보내기와 상태 표시줄 메뉴의 짧은 목록은 틀 7개에 "일반 문서 (맺음 줄)"과 "보고서 (표지)"를 더한 9줄, 한림대 2줄, 내 양식이다. 2.7.x의 10개가 모두 한 줄씩 남는다.

### 5-6. 노트 속성

| 속성 | 영문 별칭 | 뜻 |
|---|---|---|
| `공문_기관서식` | `gongmun-agency-style` | 모양 이름: 기관 이름, 공통, 기본, 한림대 양식이나 내 양식의 이름 |
| `보도_담당자표` | `press-people` | 항목마다 "구분 / 직급 / 이름 / 전화". 보도자료의 6열 담당자 표 |

- "속성 넣기"는 보고서·계획서·개조식·업무보고·보도자료에서 `공문_기관서식`을 넣고, 그 노트에 기관 모양이 골라져 있으면 그 이름을 채운다.
- 기존 `공문_종류` 값과 별칭은 모두 그대로 읽는다.

### 5-7. 파일 이름

- `틀_모양`을 노트의 출력 언어로 쓴다. 기본 모양은 덧붙이지 않는다. 예: `보고서_국세청`, `일반문서_한림대 일송`, `서울방침`.
- 바뀐 점: 계획서는 `보고서`, 회의록과 통지는 `일반문서`, 한림대 일송은 `일반문서_한림대 일송`으로 나온다.

## 7. 한계와 미해결 질문

- 기관 모양이 요구하는 글꼴(휴먼명조, HY헤드라인M, 한양신명조 등)이 PC에 없으면 한글에서 대체 글꼴로 보인다. 글꼴 안내와 잇는 일은 남아 있다.
- 기관 모양과 서울방침의 실제 생김새는 한컴 실표시로 확인하지 않았다. 미리보기 렌더와 XML 차이까지만 확인했다.
- 문단식 보도자료 기관(37곳)에서 엔진이 내는 "문단으로 쓰는 것을 검토하세요" 알림은 일반 엔진 알림으로 보고서에 나온다. 문단식으로 자동 변환하지는 않는다.
- 파일 이름에서 계획서·회의록·통지가 `보고서`·`일반문서`로 합쳐진다. 틀 선택을 이름에 넣을지는 정하지 않았다.
- 내 양식은 여전히 문서 종류 하나에 묶여 있다. 모양만 따로 저장해 여러 틀에 쓰는 일은 양식 편집 창 개편(M6)과 함께 본다.
- 여러 양식으로 내보내기는 모양 하나를 틀 전체에 적용한다. 틀마다 다른 기관을 고르는 일은 지원하지 않는다.
- `scripts/test-preview-ui.mjs`는 M1 이후 실패하고 있었다(같은 노트의 글자 수가 달라지면 4.25.0 조판에서 쪽 수가 8 → 9로 바뀐다). 고친 노트의 글자 수를 같게 해 통과시켰다.
