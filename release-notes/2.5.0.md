# HanMark 2.5.0 — Achmage Editorial HTML / Achmage Editorial HTML

## English

HanMark 2.5.0 turns built-in HTML export into a polished, deterministic, self-contained publishing path. **Achmage Editorial** is the new default theme, while **Classic** preserves the previous HanMark HTML appearance. HWPX, DOCX, PDF, import, templates, toolbar editing, DOCX preview, and the explicit user-initiated Pandoc boundary from 2.4.5 remain compatible.

### Achmage Editorial

- The first leading H1 becomes the document masthead and is removed once from the article body. If there is no leading H1, HanMark uses the note title.
- A fixed white, ivory, navy, blue, and teal system gives headings, callouts, tables, code blocks, and long-form text a consistent editorial hierarchy.
- Images, tables, and code adapt to narrow browser panes. A dedicated print stylesheet targets A4 output and keeps headings and major blocks from breaking awkwardly.
- The renderer is deterministic: the same Markdown, title, theme, and resolved image bytes produce the same document structure and styles.
- Choose **Classic** in HanMark settings or the export center whenever compatibility with the earlier built-in HTML appearance matters.

### Self-contained offline images

- Local Vault and remote HTTP(S) PNG, JPEG, GIF, and BMP images are validated and embedded as data URIs.
- The saved HTML does not depend on the original Vault path or image server after a successful export.
- Existing safety budgets remain in force: up to 100 images, 20 MB per image, 200 MB total, with at most four concurrent loads.
- Image failures are never silent. HanMark offers retry, export with an explicit missing-image label, or cancellation.
- Unsupported image formats are not copied through as external resources.

### Script-free security boundary

Generated Achmage Editorial HTML contains no JavaScript, event handlers, iframe, object, form action, external stylesheet, web font, CDN, or arbitrary user CSS. Ordinary links are restricted to `http:`, `https:`, and `mailto:`. Images are restricted to validated raster data URIs.

Every document includes this Content Security Policy:

```text
default-src 'none'; img-src data:; font-src data:; style-src 'unsafe-inline'; connect-src 'none'; object-src 'none'; frame-src 'none'; base-uri 'none'; form-action 'none'
```

This policy is intentionally strict. The only inline executable-like resource is the deterministic built-in stylesheet allowed by `style-src 'unsafe-inline'`; no script execution is allowed.

### Compatibility and upgrade notes

- HTML still saves as `${title}_html.html`.
- New and migrated settings default to **Achmage Editorial**. Select **Classic** to restore the earlier presentation.
- No Python, pypandoc-hwpx, Pandoc, browser extension, CDN, or font installation is needed for HTML export.
- Pandoc remains optional and is used only for explicit DOCX conversion and actual DOCX preview requests.
- Kordoc remains pinned exactly to 4.2.5 for the built-in HWP/HWPX pipeline.
- Kami is credited under the MIT License for the adapted document-design language. HanMark does not bundle Kami source, fonts, Python tools, or example content.

## 한국어

HanMark 2.5.0은 내장 HTML 내보내기를 완성도 높은 결정론적 독립형 출판 경로로 바꿉니다. 새 기본 테마는 **Achmage Editorial**이며, **Classic**을 선택하면 이전 HanMark HTML 외형을 그대로 사용할 수 있습니다. 2.4.5의 HWPX·DOCX·PDF·가져오기·템플릿·툴바 편집·DOCX 미리보기와 사용자가 직접 요청할 때만 실행되는 Pandoc 경계는 호환됩니다.

### Achmage Editorial

- 맨 앞 첫 H1을 문서 마스트헤드로 사용하고 본문에서는 한 번 제거합니다. 맨 앞 H1이 없으면 노트 제목을 사용합니다.
- 고정된 white, ivory, navy, blue, teal 체계로 제목·콜아웃·표·코드 블록과 장문 본문에 일관된 편집 계층을 적용합니다.
- 이미지·표·코드는 좁은 브라우저 화면에 맞게 줄어듭니다. A4 전용 인쇄 스타일은 제목과 주요 블록이 어색하게 갈라지는 것을 줄입니다.
- 동일한 Markdown, 제목, 테마와 이미지 바이트는 동일한 문서 구조와 스타일을 만듭니다.
- 이전 내장 HTML 외형과의 호환이 필요하면 HanMark 설정 또는 내보내기 센터에서 **Classic**을 선택할 수 있습니다.

### 이미지가 포함된 오프라인 독립형 결과

- Vault 로컬 및 원격 HTTP(S) PNG·JPEG·GIF·BMP 이미지를 검증해 data URI로 포함합니다.
- 성공적으로 내보낸 HTML은 원래 Vault 경로나 이미지 서버 없이도 열립니다.
- 기존 안전 제한인 이미지 100개, 이미지당 20MB, 전체 200MB, 동시 로드 최대 4개를 유지합니다.
- 이미지 실패는 조용히 지나가지 않습니다. 재시도, 명시적인 누락 표시로 내보내기, 취소 중 하나를 선택합니다.
- 지원하지 않는 이미지 형식은 외부 주소로 그대로 통과시키지 않습니다.

### 스크립트 없는 보안 경계

생성된 Achmage Editorial HTML에는 JavaScript, 이벤트 핸들러, iframe, object, form action, 외부 스타일시트, 웹 글꼴, CDN과 임의 사용자 CSS가 없습니다. 일반 링크는 `http:`, `https:`, `mailto:`만 허용하고, 이미지는 검증된 raster data URI만 허용합니다.

모든 문서에 다음 Content Security Policy를 넣습니다.

```text
default-src 'none'; img-src data:; font-src data:; style-src 'unsafe-inline'; connect-src 'none'; object-src 'none'; frame-src 'none'; base-uri 'none'; form-action 'none'
```

이 정책은 의도적으로 엄격합니다. `style-src 'unsafe-inline'`이 허용하는 것은 결정론적인 내장 스타일시트뿐이며 스크립트 실행은 허용하지 않습니다.

### 호환성과 업데이트 안내

- HTML 저장 파일명은 `${title}_html.html`을 유지합니다.
- 새 설정과 이전 설정의 마이그레이션 결과는 **Achmage Editorial**이 기본입니다. 이전 표현으로 돌아가려면 **Classic**을 선택하십시오.
- HTML 내보내기에 Python, pypandoc-hwpx, Pandoc, 브라우저 확장, CDN 또는 글꼴 설치가 필요하지 않습니다.
- Pandoc은 명시적인 DOCX 변환과 실제 DOCX 미리보기 요청에만 계속 사용하는 선택 사항입니다.
- 내장 HWP/HWPX 파이프라인의 Kordoc은 정확히 4.2.5로 유지합니다.
- 응용한 문서 디자인 언어에 대해 Kami를 MIT License로 표시합니다. HanMark에는 Kami 소스·글꼴·Python 도구·예제 콘텐츠를 포함하지 않습니다.
