# HanMark 3.0.0 — Kordoc 4.25, frames and looks, diagrams, and built-in DOCX

HanMark 3.0.0 moves the engine from Kordoc 4.15.7 to Kordoc 4.25.0 and adds official documents chosen as a frame and a look (with 52 central-agency looks), Mermaid diagrams drawn in every export, a built-in DOCX writer that needs no Pandoc, HWP to HWPX conversion, and a working document checker. Everything still runs offline and uses no AI tokens. Requires Obsidian 1.8.9 or later on desktop.

## What is new

- **Engine:** Kordoc 4.25.0 with its new PDF engine (hayro) built into the plugin. Kordoc's Hancom Office automation and OCR code are removed from the plugin file, and the plugin file contains no network call.
- **Official documents as 틀 (frame) and 모양 (look):** seven frames (기안문, 일반 문서, 보고서, 개조식 보고서, 업무보고, 보도자료, 서울방침) and a look chosen separately: 기본, 공통, 52 central agencies, the two Hallym University looks, or your own. The look chooser searches by name and keeps recent and favourite looks on top. 보고서 has **표지** and **목차** switches; 서울방침 is new. Agency looks apply to 보고서, 개조식 보고서, 업무보고, and 보도자료; they change fonts, sizes, bullet marks, table header shading, and band colour, not the page structure.
- **한림대 AI융합연구원 보고서 표지에 학교 상징:** the cover of the AI Convergence Research Institute report look shows the Hallym University emblem centred at the bottom.
- **내 양식의 표지 로고:** add your organization's logo (PNG, JPG, SVG, or WebP) to a look of your own; it is centred at the bottom of the cover, with its width and height above the page edge set in the style window. Start the look from one of the 52 agencies to get that agency's fonts and colours with your logo. HanMark ships no government logos: the government symbol may not be used without permission.
- **견본으로 내 모양 만들기:** make your own look from a sample HWPX (page setup, fonts, paragraph shapes, table look) or from a report PDF, see what was taken and what was not, and share it as a `.kpack` file.
- **Mermaid diagrams:** `mermaid` code blocks are drawn as diagrams in HWPX, DOCX, HTML, and Editorial PDF with the colours and font the note shows. `%% @caption` becomes the caption and `%% @alt` the alternative text. A diagram that cannot be drawn stays a code block and is listed in the report.
- **Built-in DOCX:** DOCX export and the DOCX preview work without Pandoc on Windows and macOS, from the same Word template settings. **고급 (Pandoc)** remains as a choice for documents that need Word equation objects.
- **Import:** tables are written as Obsidian tables by default (two other choices), sub/superscripts are kept as `<sup>`/`<sub>`, borderless layout tables are unwrapped into text by default, and PPTX, Hangul memos, and in-place PDF pictures are supported.
- **HWPX로 변환:** convert `.hwp` files to HWPX from the document viewer, the file menu, or a command. HWP forms can be filled; the result is HWPX.
- **공문서 표기 점검:** notation, bullet-style wording, and budget arithmetic checks in one window with filters, jump to the text, fix, and ignore; optional underlines in the editor and an optional check before export.
- **내보낼 때:** per export, **Mermaid 도식을 그림으로**, **주석을 한글 메모로** (`==글==%%메모%%`), and **수식을 한글 수식 개체로**.

## Behavior changes

- The list of ten official-document forms is replaced by frame and look. 계획서 is 보고서 with **표지** on; 회의록 and 통지·안내 are 일반 문서. Existing notes (`공문_종류`), stored forms, your own forms, and per-note form memory are converted when settings load.
- Exported official-document file names use the frame and the look (`보고서_국세청`), so 계획서 files are now named 보고서 and 회의록/통지 files 일반문서.
- Imported notes look different from 2.7: pipe tables instead of HTML for merged tables (merged cells are flattened and stay flattened on re-export), `<sup>`/`<sub>` tags, and layout tables as text (the layout is not rebuilt on re-export). Each default can be changed in the import window.
- Sub/superscripts in a note are now exported to HWPX as real sub/superscripts (2.7 dropped them).
- DOCX no longer needs Pandoc. Users who had set a custom Pandoc path keep the Pandoc engine.
- The plugin file is about 6.3 MB (4.3 MB in 2.7.1), mostly the PDF engine and the diagram engine.

## Known limits

- Nothing in this release was checked in Hancom Office itself. HWPX output was validated and re-read with Kordoc and drawn with Kordoc's preview; DOCX was opened in Microsoft Word; windows were driven in Chromium. All of this ran on Windows; macOS and Linux were not run locally.
- HWPX holds diagrams as pictures, so shapes cannot be edited in Hangul. A diagram inside a quote or callout is placed after it in HWPX. HWPX pictures have no alternative text.
- HWP 3.x conversion keeps text, tables, and pictures but not formatting. Distribution-locked and encrypted HWP 5 files were not tested.
- Memos in table cells are attached on export, but on import they are listed at the end of the note instead of returning to their place; memo times are not kept. The HWPX preview does not draw memos and shows equations as approximate text.
- A look made from a PDF takes only bullet levels, line spacing, band colour, and the left margin. A look used "as the sample" skips cover, contents, equations, and HanMark's finishing.
- The built-in DOCX writer keeps LaTeX equations as text.
- Check messages come from Kordoc and are in Korean, also in the English interface. Text that comes from embedded notes is not checked. Bullet-style wording rules run only for 보고서 and 개조식 보고서, the frames written in that style.
- A note cannot be saved back into the HWP/HWPX file it was imported from; exporting always makes a new file (unchanged since 2.4.5).

## Upgrading

Settings from 2.7.x load without loss. Open the export window once to see the frame and look that replaced your last form. To get 2.7-style imports, choose **합쳐진 표는 HTML**, turn off **위첨자·아래첨자 표시**, and turn off **테두리 없는 표를 글로 풀기** in the import window; the choices are remembered.

Obsidian installed from an installer older than mid-2023 (Electron 25 or earlier, Chromium below 115) cannot run the document engine, even when the app itself has updated to a current version: that Chromium refuses to compile the engine's XML parser. HanMark shows a message asking you to download the current Obsidian installer and install it again. The minimum app version stays 1.8.9, because an app version cannot tell which installer is in use.

## Validation

`npm run check` (609 tests, lint, interface-text check, type check, build, bundle, Community, and release checks), the Editorial PDF render test, and nine browser scripts for the export, import, look, check, preview, toolbar, and conversion windows.
