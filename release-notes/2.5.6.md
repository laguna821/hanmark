# HanMark 2.5.6 — Custom PDF Theme Builder / 사용자 PDF 테마 빌더

## English

HanMark 2.5.6 keeps the proven Achmage HanMark Editorial PDF as an immutable built-in design and adds a novice-friendly library of reusable custom PDF themes.

### Build a theme from one color

- Choose one six-digit sRGB key color with the native picker or enter its HEX value directly.
- HanMark derives readable text, brand ink, rules, soft backgrounds, code, callout, and table colors with deterministic WCAG contrast calculations.
- The chosen color remains the exact key saved in the theme, picker, and exported JSON. Only while the key-background text is automatic may HanMark use a slightly darker surface behind text, limited by the product to an OKLab distance (`ΔEOK`) of `0.02`.
- The final quantized text/background pair must pass the WCAG `4.5:1` minimum. If that small adjustment cannot pass, HanMark returns to the exact key surface and its safe foreground—for example, dark text on a bright yellow key.
- Three advanced foreground/rule colors remain manually overridable. Manually setting the key-background text switches off the surface correction and uses the exact key surface. Unsafe manual choices are still respected and accompanied by the measured contrast ratio and a persistent warning.

### Reusable named themes

- The original Achmage HanMark theme cannot be overwritten, renamed, or deleted and reproduces the 2.5.5 output exactly.
- Create, duplicate, rename, edit, select, and delete any number of named themes in the current Vault.
- The PDF export center remembers the selected theme and shows its color and readability status before printing.
- Export one theme as JSON or import it as a new non-overwriting user theme. IDs, local paths, timestamps, and active settings are not shared.

### Fully editable page furniture

- Customize or intentionally blank the cover kicker, edition, title, subtitle, brand, system label, detail line, and tags.
- Customize or blank the page header and footer, choose file-name/custom/blank title modes, and toggle page numbers.
- Blank text removes its glyphs while preserving the established A4 layout slots.

### Safety and compatibility

- The theme builder accepts typed fields only—never raw CSS, HTML, or Markdown templates.
- Theme JSON uses the existing explicit browser file picker and adds no network, clipboard, direct filesystem, process, analytics, or runtime dependency capability.
- The A4 geometry, 52/48 cover, embedded Pretendard fonts, first-print readiness, print lock, cleanup, Markdown parser, HWPX, DOCX, HTML, imports, and existing commands remain unchanged.
- HanMark uses WCAG contrast formulas to assist readability; this feature alone is not a claim that an exported PDF fully conforms to WCAG.

### Upgrade notes

- HanMark 2.5.6 requires desktop **Obsidian 1.8.9 or newer**.
- HWPX, HTML, and PDF require no Python, pypandoc-hwpx, or Pandoc installation.
- Pandoc remains optional and is used only for DOCX generation and explicitly requested actual DOCX preview.

## 한국어

HanMark 2.5.6은 검증된 Achmage HanMark Editorial PDF를 수정 불가능한 기본 디자인으로 유지하면서, 초보자도 반복 사용할 수 있는 사용자 PDF 테마 라이브러리를 추가합니다.

### 키 컬러 하나로 테마 만들기

- 운영체제 컬러 선택창에서 6자리 sRGB 키 컬러를 고르거나 HEX 값을 직접 입력합니다.
- HanMark가 WCAG 대비 계산으로 글자, 브랜드 잉크, 실선, 연한 배경, 코드, 콜아웃과 표 색을 결정적으로 파생합니다.
- 고른 색은 테마·선택창·내보낸 JSON의 키 컬러로 정확히 그대로 저장됩니다. 키 배경 위 글자가 자동일 때만, 글자가 놓이는 면을 제품 상한인 OKLab 색차(`ΔEOK`) `0.02` 이내에서 조금 어둡게 사용할 수 있습니다.
- 최종 양자화된 글자·배경 조합이 WCAG `4.5:1` 최소선을 통과할 때만 그 면을 적용합니다. 가까운 범위에서 통과하지 못하면 원래 키 면과 안전한 글자색으로 돌아갑니다. 예를 들어 밝은 노랑에는 어두운 글자를 사용합니다.
- 고급 글자·실선 3색은 직접 덮어쓸 수 있습니다. 키 배경 위 글자를 직접 지정하면 면 자동 보정이 꺼지고 입력한 키 컬러 면을 그대로 사용합니다. 낮은 대비를 선택해도 강제로 바꾸지 않고 실제 비율과 지속적인 경고를 표시합니다.

### 다시 쓰는 이름 있는 테마

- Achmage HanMark 기본 테마는 덮어쓰기·이름 변경·삭제할 수 없고 2.5.5 출력을 정확히 재현합니다.
- 현재 Vault에서 이름 있는 테마를 제한 없이 생성·복제·이름 변경·편집·선택·삭제할 수 있습니다.
- PDF 내보내기 센터는 마지막 선택을 기억하고 인쇄 전에 색상과 가독성 상태를 보여 줍니다.
- 테마 하나를 JSON으로 내보내거나 기존 것을 덮어쓰지 않는 새 사용자 테마로 가져옵니다. ID·로컬 경로·시간·활성 설정은 공유하지 않습니다.

### 표지와 페이지 문구 전체 편집

- 표지 kicker, edition, 제목, 부제, 브랜드, 시스템 문구, 상세 문구와 태그를 바꾸거나 비울 수 있습니다.
- 페이지 머리말·꼬리말을 바꾸거나 비우고, 파일명·직접 입력·빈 제목 방식을 고르며 쪽 번호를 끌 수 있습니다.
- 빈 문구는 글자만 숨기고 기존 A4 자리 구조를 유지합니다.

### 안전성과 호환성

- 테마 빌더는 정해진 입력만 받으며 원시 CSS·HTML·Markdown 템플릿을 받지 않습니다.
- 테마 JSON은 기존 사용자 명시 브라우저 파일 선택창을 사용하며 네트워크·클립보드·직접 파일시스템·프로세스·분석·런타임 의존 권한을 추가하지 않습니다.
- A4 geometry, 52/48 표지, 내장 Pretendard, 첫 인쇄 준비, 인쇄 잠금·정리, Markdown parser, HWPX·DOCX·HTML·가져오기와 기존 명령은 그대로입니다.
- HanMark는 WCAG 대비 공식을 가독성 보조에 사용합니다. 이 색상 기능 하나로 PDF 전체의 WCAG 준수를 주장하지 않습니다.

### 업데이트 참고

- HanMark 2.5.6은 데스크톱 **Obsidian 1.8.9 이상**이 필요합니다.
- HWPX·HTML·PDF에는 Python, pypandoc-hwpx 또는 Pandoc 설치가 필요하지 않습니다.
- Pandoc은 DOCX 생성과 사용자가 명시적으로 요청한 실제 DOCX 미리보기에만 선택적으로 사용합니다.
