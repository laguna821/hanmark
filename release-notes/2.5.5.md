# HanMark 2.5.5 — First-print reliability and PDF toolbar / 최초 인쇄 안정화와 PDF 툴바

## English

HanMark 2.5.5 makes the first Editorial PDF export after a fresh Obsidian launch as reliable as every later export and adds a directly discoverable PDF button to the top toolbar.

### Reliable first PDF after launch

- HanMark waits until its attached print stylesheet, embedded Pretendard weights, document images, and print layout are ready before opening the native print dialog.
- The first export now receives the same complete full-bleed cover, headers, footers, rules, and page numbering as subsequent exports.
- The existing bounded wait and fail-closed behavior remain in place: HanMark does not silently print a known-incomplete document.

### PDF in the top toolbar

- A PDF button now appears beside the HWPX, DOCX, and HTML export buttons.
- The button opens the unified export center with PDF selected, so users can review the PDF description before starting the native print flow.
- The existing `export-pdf` command ID and command-palette workflow remain available.

### Compatibility

- The 2.5.4 theme-independent fixed light Editorial palette is unchanged.
- The full-bleed cover, branded page furniture, actual page numbers, large-code splitting, adaptive table layout, safe deep-structure handling, and imported BMP rendering remain unchanged.
- HWPX, DOCX, HTML, document import, templates, CMDS Eagle integration, Markdown source handling, and existing command IDs are unchanged.

### Upgrade notes

- HanMark 2.5.5 requires desktop **Obsidian 1.8.9 or newer**.
- HWPX, HTML, and PDF require no Python, pypandoc-hwpx, or Pandoc installation.
- Pandoc remains optional and is used only for DOCX generation and the explicitly requested actual DOCX preview.

## 한국어

HanMark 2.5.5는 Obsidian을 새로 실행한 뒤 처음 만드는 Editorial PDF도 이후 내보내기와 동일하게 안정화하고, 상단 툴바에서 PDF를 바로 찾을 수 있게 합니다.

### 최초 PDF 내보내기 안정화

- 연결된 인쇄 스타일시트, 내장 Pretendard 굵기, 문서 이미지와 인쇄 조판이 준비될 때까지 기다린 뒤 네이티브 인쇄 창을 엽니다.
- 최초 내보내기에도 이후 내보내기와 동일하게 완성된 전면 표지, 머리말·꼬리말, 실선과 쪽 번호가 적용됩니다.
- 기존의 제한 시간과 실패 폐쇄 방식은 유지합니다. 불완전하다고 확인된 문서를 조용히 인쇄하지 않습니다.

### 상단 툴바의 PDF

- HWPX·DOCX·HTML 내보내기 버튼 옆에 PDF 버튼을 추가했습니다.
- 버튼을 누르면 PDF가 선택된 통합 내보내기 센터가 열리므로 설명을 확인한 뒤 네이티브 인쇄 절차를 시작할 수 있습니다.
- 기존 `export-pdf` 명령 ID와 명령 팔레트 사용 방법은 유지합니다.

### 호환성

- 2.5.4의 테마 독립형 고정 라이트 Editorial 팔레트는 바뀌지 않습니다.
- 전면 표지, 브랜드 페이지 장식, 실제 쪽 번호, 대형 코드 분할, 표 자동 배치, 깊은 구조 안전 처리와 가져온 BMP 렌더링을 그대로 유지합니다.
- HWPX·DOCX·HTML, 문서 가져오기, 템플릿, CMDS Eagle 연동, Markdown 원문 처리와 기존 명령 ID는 바뀌지 않습니다.

### 업데이트 참고

- HanMark 2.5.5는 데스크톱 **Obsidian 1.8.9 이상**이 필요합니다.
- HWPX·HTML·PDF에는 Python, pypandoc-hwpx 또는 Pandoc 설치가 필요하지 않습니다.
- Pandoc은 DOCX 생성과 사용자가 명시적으로 요청한 실제 DOCX 미리보기에만 선택적으로 사용합니다.
