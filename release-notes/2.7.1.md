# HanMark 2.7.1 — Editorial PDF paper stays white in dark mode

HanMark 2.7.1 is a bug-fix release. Requires Obsidian 1.8.9 or later on desktop.

## Fixed

- **Editorial PDF in a dark theme:** when Obsidian used a dark theme, the margins of every body page (where the header, footer, and page number sit) printed black, so the white text area looked like a sheet laid on a dark background. Chromium paints page margins with the window background, and Obsidian sets that color from the active theme. HanMark now paints every PDF page with the paper color, so the PDF looks the same in light and dark mode. Nothing changes for light-theme users.
